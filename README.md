# arslan-portfolio

Personal portfolio site.

## Branches

| Branch    | Purpose                                          |
| --------- | ------------------------------------------------ |
| `main`    | Production. Only merged from `develop` via PR.    |
| `develop` | Integration branch. Feature branches merge here.  |

Feature work is done on `feature/<name>` branches cut from `develop`.
